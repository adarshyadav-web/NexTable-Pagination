# NexTable Pagination

A dynamic data table management system with smooth page-based navigation and professional status indicators.

## 🚀 Features

- **Dynamic Data Rendering**: Efficiently handles large datasets.
- **Interactive Pagination**: Page-by-page navigation with active states.
- **Status Badges**: Visual categorization of table entries.
- **Clean UI**: High-contrast, readable table design.

## 🛠️ Technologies Used

- **HTML5**, **CSS3**, **JavaScript**
